# SPTDevSuite 0.2.0 for SPT 4.1.3

Status: experimental release candidate; not published.

## Compatibility

- Exact official SPT 4.1.3 only.
- .NET 10 server mod; no client plugin.
- NuGet package IDs are `SPTushonka.*` 4.1.3 while runtime assembly and namespace identities remain `SPTarkov.*`.

## Included

The release ZIP contains exactly:

- `SPTDevSuite.Contracts.dll`
- `SPTDevSuite.Server.dll`

No SPT runtime, third-party assembly, profile, database, or rollback file is included.

- Migrated the exact compatibility policy and build dependencies from SPT 4.1.2 to 4.1.3.

- Added fail-closed compatibility checks at startup, state-changing HTTP routing, and the unlock-service entry point.
- Corrected dashboard version reporting to use the declared mod version.

## Experimental installation

1. Stop SPT Server, SPT Launcher, and EFT.
2. Verify the downloaded ZIP against its `.sha256` sidecar.
3. Back up an existing `SPT_Runtime\user\mods\SPTDevSuite` directory, if present.
4. Extract the two DLLs to `SPT_Runtime\user\mods\SPTDevSuite`.
5. Start exact official SPT 4.1.3 and open `/devsuite` from the local server origin.
6. Use a disposable profile. Confirm Overview, Items, and Profile before running an Unlocks Preview.
7. Do not Apply until Preview is correct. `CompleteQuests` additionally requires `COMPLETE_ALL_QUESTS` and does not replay quest rewards or mail.
