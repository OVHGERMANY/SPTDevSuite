# SPTDevSuite 0.2.0 for SPT 4.1.3

SPTDevSuite 0.2.0 is the normal server-mod release for exact official SPT 4.1.3 on .NET 10. It adds a local development dashboard without a client plugin or a second network listener.

## Install

1. Download `SPTDevSuite-0.2.0-SPT-4.1.3.zip`.
2. Stop SPT Server, SPT Launcher, and EFT.
3. Extract the ZIP into the SPT installation directory that contains `SPT_Runtime`.
4. Confirm these files exist:
   - `SPT_Runtime\user\mods\SPTDevSuite\SPTDevSuite.Contracts.dll`
   - `SPT_Runtime\user\mods\SPTDevSuite\SPTDevSuite.Server.dll`
5. Start exact official SPT 4.1.3 and open `/devsuite` on the configured local server origin.

Back up any existing `SPTDevSuite` directory before replacement. Use a disposable or separately backed-up profile for the first Apply, and verify Preview first.

## Included features

- Loopback-only Overview, Items, Profile, Unlocks, and Settings pages.
- Preview-first item examination, flea unlock, profile level, trader, and skill operations.
- Separately confirmed quest completion using `COMPLETE_ALL_QUESTS`; it marks quests successful without replaying rewards or mail.
- Process-lifetime dashboard authentication, anti-CSRF checks, rollback payloads, clone validation, supported profile saves, and redacted auditing.
- Exact-version fail-closed checks at startup, state-changing HTTP routing, and unlock-service entry.
